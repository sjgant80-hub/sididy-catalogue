a oracle·notes·vault·cascade workshop

A sovereign single-file build: it runs from this one file, works offline, and sends nothing anywhere.

the oracle

Type a real decision. It looks for signals it can name and ranks a few honest stances — with no signal it says so and ranks by stated defaults.

notes that stay

Everything typed here is saved on this machine, in this browser, and nowhere else.

the vault

One note, locked with AES-GCM on this machine. The password never leaves the field, is never stored, and there is no reset — that is the point.

the cascade

The fall-os walk, trimmed: free deterministic code answers first; then a model you own (Ollama on your machine); then — only if you set a key — a rented frontier model. This build can reach exactly two places, both yours: localhost:11434 (your machine) and api.anthropic.com (your key). Nothing else, and never without you pressing the button.
